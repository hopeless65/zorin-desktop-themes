# Zorin Desktop Themes

The Zorin OS desktop theme provided in a variety of color combinations.

## GNOME Shell 48 support

The `gnome-48` branch adds GNOME Shell 48 compatibility for the
ZorinBlue-Light and ZorinBlue-Dark themes, based on Zorin Desktop
Themes 5.2.3.

The compatibility layer includes adjustments for:

- Quick Settings and split Quick Toggles
- notifications and message lists
- date menu and calendar controls
- modal and end-session dialogs
- screenshot and OSD controls
- GNOME Shell 48 widget selector changes
- dark-theme control and disabled-state fine tuning

The original ZorinBlue-Light and ZorinBlue-Dark colors and visual style
are preserved where possible, while GNOME Shell 48-specific selectors
and widgets are adapted to the existing Zorin theme palettes.

### Included themes

- **ZorinBlue-Light** — GNOME Shell 48 compatibility and visual fine tuning
- **ZorinBlue-Dark** — GNOME Shell 48 compatibility and visual fine tuning

The `master` branch remains aligned with the original Zorin Desktop
Themes repository. The `gnome-48` branch contains the GNOME Shell 48
adaptations for the two ZorinBlue themes.
